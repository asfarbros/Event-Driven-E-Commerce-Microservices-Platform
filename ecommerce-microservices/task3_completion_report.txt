4. REST API ROUTES
--------------------------------------------------------------------------------

  ┌─────────┬────────────┬───────────────────────────────────────────────────┐
  │ Method  │ Path       │ Description                                       │
  ├─────────┼────────────┼───────────────────────────────────────────────────┤
  │ GET     │ /          │ Fetch all products from MongoDB                   │
  │ GET     │ /cart      │ Fetch user's cart from Redis (x-user-id header)   │
  │ POST    │ /cart      │ Add/update item in cart (productId, quantity)      │
  │ DELETE  │ /cart      │ Clear the user's entire cart                      │
  │ GET     │ /health    │ Health check endpoint                             │
  └─────────┴────────────┴───────────────────────────────────────────────────┘

  Cart Routes Details:
  ────────────────────
  • All cart routes require the `x-user-id` header.
  • The Redis key is formatted as `cart:<userId>`.
  • POST /cart body: { "productId": "<id>", "quantity": <number> }
    - If the productId already exists in the cart, its quantity is updated.
    - Otherwise, a new entry is appended.
  • DELETE /cart removes the entire Redis key for the user.


5. DATABASE CONNECTION STRINGS (.env template)
--------------------------------------------------------------------------------

  PORT=3001
  MONGO_URI=mongodb://ecom_user:ecom_pass@localhost:27017/ecom_db?authSource=admin
  REDIS_URL=redis://:ecom_pass@localhost:6379

  Notes:
  • The MongoDB URI uses the credentials from docker-compose.yml
    (ecom_user / ecom_pass), targeting the ecom_db database.
  • authSource=admin is required because MONGO_INITDB_ROOT_USERNAME
    creates the user in the admin database.
  • The Redis URL includes the password configured via --requirepass
    in docker-compose.yml.
  • When running inside Docker (docker-compose), replace `localhost`
    with the service names (e.g., mongodb, redis).

8. QUICK START
--------------------------------------------------------------------------------

  # Make sure infrastructure is running:
  cd ecommerce-microservices
  docker compose up -d

  # Start the catalog-cart-service:
  cd catalog-cart-service
  npm run dev

  # Test endpoints:
  curl http://localhost:3001/            # list products
  curl http://localhost:3001/health      # health check

  # Cart (requires x-user-id header):
  curl -H "x-user-id: user123" http://localhost:3001/cart

  curl -X POST http://localhost:3001/cart \
    -H "Content-Type: application/json" \
    -H "x-user-id: user123" \
    -d '{"productId":"abc123","quantity":2}'

  curl -X DELETE -H "x-user-id: user123" http://localhost:3001/cart

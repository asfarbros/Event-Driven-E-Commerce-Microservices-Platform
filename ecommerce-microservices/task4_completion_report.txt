5. COMPONENT OVERVIEW
--------------------------------------------------------------------------------

  Navbar
  ──────
  • Logo with Lucide Store icon
  • Navigation links: Catalog, Cart (with active state highlighting)
  • Clerk SignInButton (when signed out) / UserButton (when signed in)
  • All links use neo-brutalist card style with hard offset shadows

  ProductCard
  ───────────
  • Deterministic color assignment from 6-color palette
  • Product name, description, price, stock count
  • "Add to Cart" button with Lucide ShoppingCart icon
  • Thick black borders, hard offset shadows, hover press effect

  CatalogPage
  ───────────
  • Fetches products from GET /api/catalog via API Gateway
  • Renders responsive 3-column grid of ProductCards
  • Add to Cart sends POST /api/catalog/cart with Clerk Bearer token
  • Loading, error, and empty states with Lucide icons

  CartPage
  ────────
  • Fetches cart from GET /api/catalog/cart with auth headers
  • Renders items in a neo-brutalist table (Product ID, Quantity, Status)
  • "Clear Cart" button (DELETE /api/catalog/cart)
  • Bold CHECKOUT placeholder button (will POST /api/orders in future)
  • Sign-in prompt if user is not authenticated
